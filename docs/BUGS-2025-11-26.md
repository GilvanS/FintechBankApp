## Bug #1: CPF Input Field Permitindo Mais de 11 Dígitos

**Tela Afetada:** Cadastro (SignUp)  
**Plataforma:** Mobile (Android/iOS)  
**Severidade:** Média  
**Status:** ✅ Corrigido em 26/11/2025

### Descrição

O campo de CPF no formulário de cadastro estava aceitando mais de 11 dígitos.

### Comportamento Atual

O campo de CPF agora:
- Aceita apenas números
- Formata automaticamente como xxx.xxx.xxx-xx
- Limita a entrada a exatamente 11 dígitos

### Solução Aplicada

1. **Arquivo `MOBILE/src/utils/formatters.ts`**:
   - Modificada função `formatCPF` para incluir `.slice(0, 11)` antes do regex
   - Garante que apenas 11 dígitos sejam processados

2. **Arquivo `MOBILE/src/components/SignUp.tsx`**:
   - Atualizado para usar `formatCPF` no onChange
   - Adicionado `inputMode="numeric"` para abrir teclado numérico
   - Adicionado `placeholder="000.000.000-00"`

## Bug #2: Campos de Limite no Admin Não Aceitando Formatos Flexíveis

**Tela Afetada:** Admin Panel  
**Plataforma:** Mobile/Web  
**Severidade:** Média  
**Status:** ✅ Corrigido em 26/11/2025

### Descrição

Os campos "Limite Total", "Limite Disponível" e "Limite PIX" no painel Admin não aceitavam formatos flexíveis (ex: `5000` vs `5000.00`), causando erros de conversão.

### Solução Aplicada

1. **Arquivo `MOBILE/src/components/Admin.tsx`**:
   - Mudado `type="number"` para `type="text"` com `inputMode="decimal"`
   - Adicionados handlers `onChange` para aceitar apenas números, pontos e vírgulas
   - Adicionados handlers `onBlur` para formatar automaticamente com 2 casas decimais
   - Funções `handleUpdateCreditLimit` e `handleUpdatePixLimit` agora convertem para `Number` e aplicam `toFixed(2)` antes de enviar para API

## Bug #5: Campo de Senha Sem Teclado Numérico e Toggle de Visibilidade

**Tela Afetada:** Login e Cadastro  
**Plataforma:** Mobile (Android/iOS)  
**Severidade:** Média  
**Status:** ✅ Corrigido em 26/11/2025

### Descrição

**PIN (modal de confirmação)**: deve usar teclado numérico
**Senha (login)**: deve continuar alfanumérico (aceita letras, números e caracteres especiais)

Ambos devem ter toggle de visibilidade (ícone de olho).

### Comportamento Atual

- Campo de senha sem opção para mostrar/ocultar texto
- Teclado padrão em vez de numérico

### Solução Aplicada

1. **Login (`MOBILE/src/pages/Login/index.tsx`)**:
   - Mantido teclado alfanumérico (sem `inputMode`)
   - Adicionado estado `showPassword`
   - Input com `type={showPassword ? "text" : "password"}`
   - Botão de toggle com ícone Material `visibility` / `visibility_off`

2. **PIN Modal (`MOBILE/src/components/PasswordModal.tsx`)**:
   - Adicionado `inputMode="numeric"` para teclado numérico
   - Adicionado estado `showPassword`
   - Input com `type={showPassword ? "text" : "password"}`
   - Botão de toggle com ícone Material `visibility` / `visibility_off`
